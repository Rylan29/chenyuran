任务二 · Swiper 第 7 种效果：creative 自定义变换

课堂上讲了 slide / fade / cube / coverflow / flip / cards 六种，其实 Swiper 还有第 7 种 —— creative，让你手工指定前一张、后一张 slide 的 transform。

效果目标：切换时，上一张缩小 + 左移 + 轻微旋转（"退后一点让位子"）；下一张放大 + 右移（"大步向前登场"）。这就是 creativeEffect.prev 和 creativeEffect.next 两个配置对象各管一边。

下一张 slide 的变形

next: { // X方向移出去 + 稍微放大（用 CSS 百分比） translate: ['120%', 0, 0], // 不旋转，保持正面朝你 rotate: [0, 0, 0], // 完全不透明 opacity: 1, // 稍大一点，像在"向前扑" scale: 1.15, shadow: true }

✨ 完整 Swiper 初始化

抄这段就行
var demo = new Swiper("#creativeDemo", { effect: 'creative', loop: true, speed: 800, autoplay: { delay: 2500, disableOnInteraction: false }, grabCursor: true, // ====== creative effect 的核心 ====== creativeEffect: { perspective: true, // 开启透视，Z 轴偏移才有 3D 感 progressMultiplier: 1, // 变换强度倍数，改大更夸张 // ← 左边那张退场时的样子 prev: { translate: [-60, 0, -200], rotate: [0, 0, -8], opacity: 0.4, scale: 0.75, shadow: true }, // → 右边那张登场时的样子 next: { translate: ['120%', 0, 0], rotate: [0, 0, 0], opacity: 1, scale: 1.15, shadow: true } }, pagination: { el: "#crePag", clickable: true } });

creativeEffect 参数速查表

参数类型它控制什么改大 / 改小会怎样
perspective boolean 是否开启 3D 透视 true 时 Z 轴偏移生效，prev 会像"沉"到背景去
prev object 上一张 slide 的 transform（左边那张，即将退场） 只管退场态，跟 next 没关系
next object 下一张 slide 的 transform（右边那张，即将登场） 只管登场态，跟 prev 没关系
translate [x,y,z] X/Y/Z 三轴位移（像素或百分比字符串） X 负值=左移，正值=右移；Z 负值=变远变小
rotate [x,y,z] X/Y/Z 三轴旋转角度（单位：度） Z 轴负=逆时针，正=顺时针；Y 轴=翻转效果
opacity 0~1 透明度 0 完全透明，1 完全不透明
scale number 缩放比例 0.5 一半大，1.5 一半大，1 原样
progressMultiplier number 整体变换强度放大系数 2 所有 translate/rotate/opacity 变化都翻倍，效果更夸张
