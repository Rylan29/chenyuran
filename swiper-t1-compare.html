02 把中文需求翻译成参数

答辩时最容易被追问的是"这句话对应哪个参数"。这张表就是交卷前该背下来的东西。

老师的要求（中文）对应参数为什么是它
让 Swiper 可以拖动 new Swiper("#id", {}) 一个空配置对象就已经启用了 touch / mouse 事件
显示圆点分页器 pagination: { el: "#xxx" } el 指定哪个 DOM 当分页器，不给 el 就画不出来
圆点能点击跳转（不是摆设） pagination: { el }
pagination: { el, clickable: true }		 默认 clickable: false，圆点只是视觉提示。加了这一行 Swiper 才会绑定 click 事件
最后一张继续往后翻会回到第一张 loop: true 无缝循环模式，需要 Swiper 在首尾各克隆一张 slide 做衔接
切换动画慢一点 speed: 600 单位是毫秒，默认 300；数值越大切换越慢
左右箭头可点 navigation: { prevEl, nextEl } 指向你 HTML 里那两个 swiper-button-prev/next 的选择器
每隔 3 秒自动翻页 autoplay: { delay: 3000 } 默认不自动播，必须显式写 autoplay 配置对象
用户拖了一下，自动播放不要停 autoplay: { disableOnInteraction: false } 默认 true，手一摸就停；改成 false 才会接着播
